# HTTP/2 Frame Test Case

Test vectors from [http2jp/http2-frame-test-case](https://github.com/http2jp/http2-frame-test-case).

These fixtures contain HTTP/2 frame encoding/decoding test cases for all frame types (DATA, HEADERS, PRIORITY, RST_STREAM, SETTINGS, PUSH_PROMISE, PING, GOAWAY, WINDOW_UPDATE, CONTINUATION). They are used to verify RFC 7540/9113 compliance.
