# HPACK Test Case

Test vectors from [http2jp/hpack-test-case](https://github.com/http2jp/hpack-test-case).

These fixtures contain HPACK encoding/decoding test stories generated by various HTTP/2 implementations (nghttp2, go-hpack, haskell-http2, node-http2-hpack, python-hpack, swift-nio-hpack). They are used to verify interoperability and RFC 7541 compliance.
